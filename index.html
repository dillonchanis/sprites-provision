Sprite Kit Builder

1 · Install the sprite CLI

$ curl https://sprites.dev/install.sh | bash

Paste this into Terminal on a Mac or Linux machine (Windows: use WSL). One time per computer.

2 · Sign in

$ sprite login

Opens your browser to sign in with Fly.io. No account? Ask your admin for an invite to the team org first.

Your personal machine in the cloud — any short name works.

        Download the script, then in Terminal (from your Downloads folder):
        chmod +x provision-personal.sh && ./provision-personal.sh.
        It is safe to run again later — reruns update your existing sprite instead of creating a new one.
